# 基层帮办智能助手

面向 12345 工单承办人与人民调解员的独立 Web 工具：粘贴诉求 → 政策引用 + 条款解释 + 回复话术 + 办理方法（M1），可一键开关的类案经验（M2，基于 79,992 条枣庄真实历史工单）。

设计文档：《整体设计-v0.2.md》；测试基准：《测试样本集/》（40 条真实工单黄金集）。

---

## 快速启动

```bash
# 1) 后端依赖（已建好 .venv 可跳过；国内网络用清华镜像）
cd backend
python3 -m venv .venv
.venv/bin/pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt

# 2) 初始化账号（首次；已初始化可跳过）
.venv/bin/python -m app.seed --demo

# 3) 历史工单入库（首次；约 10 秒，产出 data/cases.db）
.venv/bin/python scripts/ingest_cases.py --sql "<已授权的工单数据源>.sql"

# 4) 启动（前端已构建进 backend/static，单进程即全部）
#    生产环境务必先完成《部署前安全清单》，再对外暴露
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
# 打开 http://127.0.0.1:8000
```

前端改动后重新构建：`cd frontend && npm install && npm run build`（产物自动输出到 backend/static）。

## 账号

初始账号由 `python -m app.seed` 生成**随机临时口令**，仅在控制台打印一次，首次登录强制改密（服务端强制，未改密前除改密外的接口一律 403）。新账号在 后台管理 → 用户管理 里创建（初始口令只显示一次）。

> 部署到新环境时请重新运行 seed 生成账号，不要沿用任何开发环境的口令。

### Prompt 与检索调优（基于真实输出）

用真实工单实测后做了多处收紧，均已写入默认与运行配置：
- **回复话术改为承办方视角（数据驱动）**：分析 8 万条真实办理情况发现，只有约 5% 的工单才引导诉求人自行处理（其中 40% 属司法/仲裁、13% 需本人材料、8% 不属受理范围），绝大多数是承办方主动"核实/协调/责成/督促/现场处置/整改"。据此重写话术规则：以"我们/我单位"第一人称体现承办人主动办理，**禁止把可协调事项简单甩给诉求人自行联系**；仅在司法/仲裁、需本人亲办、不属受理范围时才引导自办，且须同时给出材料、正确部门、可提供的协助。实测覆盖噪音/供暖/消费/邻里侵权/多层分包欠薪全谱系，话术均为承办方主动办理且边界正确。
- **防数字编造**：system prompt 增加"材料未写明的数值不得填常识数字"（含 18℃ 反例）；质量守卫新增**阈值数值核对**（温度/百分比须出现在材料中，否则黄标）。实测长文本供暖案已成功拦截模型编造的"40%入住率"。
- **防牵强引用**：prompt 要求"无关材料不引用、引用必须方括号 `[材料N]` 格式"；守卫与前端角标均兼容裸"材料N"写法。
- **检索质量**：扩充权威源白名单（普法网/检察院/最高法/人社部等），排序改为"权威/法规优先、其余保留 dknowc 相关性顺序"，`top_n` 3→4；材料卡显示适用地域，便于核对跨地市材料。实测欠薪案已能稳定命中"施工总承包单位先行清偿"关键法律点。
- **地域严格强制**：后端预置**全国 336 个地市级**（`app/geo_data.py`：地级市/自治州/地区/直辖市，源自规范性文件项目行政区划、adcode 交叉校验）。办理地域在后台**必填、自由输入**，输入与预置库比对并规范化（"临沂市"→"临沂"，接受自治州/地区全称如"凉山彝族自治州"→"凉山"；县级市如"滕州"、非法名称一律拒绝）。检索层**硬过滤**——材料标题/来源/地域含其他地市（且不含本地）即剔除，保留本地、下辖县市（如枣庄的滕州）、省级、国家级；办理地域注入生成 prompt，回答与引用严格限于本地域；材料卡显示地域徽标。实测枣庄部署下德州/烟台/徐州/连云港全部过滤，滕州/"中山路"不误伤。
  - 注：地域过滤按用户要求为**地市级**（333 地市），未做省级过滤；极少数"仅含省名、不含任何地市名"的外省材料（如"宁夏发布会"）不被拦截——绝大多数跨省材料本身带地市名，仍会被过滤。

## 后台管理（admin 登录 → 后台管理）

- **运行概览**：咨询量、活跃用户、首字耗时、空结果率、守卫违规率、近 14 天趋势、分段采纳率（内部质量信号，不用于考核）、最近守卫异常（点击直达该次咨询回放）。
- **功能与参数**：
  - **生成模型接入**：调用地址 + API Key（脱敏存储）+ 模型型号，一键**测试连接**。
  - **生成参数**：温度 / top_p / max_tokens / enable_thinking / 扩展参数（JSON 透传），并支持**以 JSON 直接编辑**整套生成配置。
  - **提示词 · 答复口径**：咨询与类案经验两套 system prompt 可直接编辑，按承办单位口径调节（保留三段标记即可）。
  - **类案经验（M2）总开关**：关闭即回到纯政策参考，立即生效。
  - **适用地域与生效时间**：逐地市部署，由后台设定，一线无需选择。
  - 政策检索 Top-N / 段落数 / 权威源三张名单 / 免责文案，全部热生效。
- **办件研判**（可选，基于历史工单结果标签）：结果区顶部一条细长「办件研判」条，三个信号点击展开——**时限研判**（同类办结中位天数+超期率，颜色分级）、**满意度处方**（同类满意率+按需 LLM 从"满意 vs 不满意"真实办理情况提炼"办到满意的关键/易导致不满意"）、**关联预警**（同小区历史同类件数，≥5 件红色标为老大难热点、列出清单）。设计上刻意做成"信号条"而非卡片,颜色自动报警、关联无则不显示、详情按需展开,避免审阅疲劳。**不做责任研判**（一线是第一责任人）。后台"功能与参数"可开关。
- **私有政策库**（可选）：导入本地市/区不公开的政策法规，平台自动**治理分段 + jieba 关键词检索**；启用后本地政策与 dknowc 结果**一并参与检索、且本地优先**，材料上标「本地政策库」徽标。支持粘贴或 .txt/.md 文件读入，可列表管理与删除。数据仅存本地 `data/private.db`，不外发。
- **咨询页呈现顺序**：回复话术 → 办理方法 → 条款解释 → 政策引用 → 类案参考（一线先看可直接采纳的话术/办法，需要核实依据再向下翻）。
- **用户管理**：建号、重置密码（临时密码只显示一次）、停用/启用。
- **咨询记录**：全量留痕检索（按人/状态/关键词），点击回放完整产出与决策。
- **审计日志**：登录、建号、重置、参数变更、测试连接等敏感操作。

## 数据与合规

- 诉求文本外发（检索/生成）前自动脱敏：身份证/手机号/固话/银行卡/车牌。
- 历史工单在入库时完成展示级脱敏（另抹楼栋门牌、来电人姓名替换）。
- 枣庄数据当前授权范围为**内部测试评估**；对外演示或 P2 产品化前需另行书面确认。
- 密钥经环境变量/`.env` 注入，不入库、不入代码仓；应用日志不落诉求原文与密钥。

## 部署前安全清单（务必逐条执行）

本项目**当前不是 git 仓库**，`backend/.gitignore` 对直接拷贝目录无效。打包/交付前必须：

1. **剔除敏感文件**：交付物不得包含 `backend/.env`、`backend/data/`（含 `jwt.secret`、`app.db`、`cases.db`、`private.db`、`server.log`）、`backend/.venv/`。用白名单打包，勿整目录 `zip`/`cp`。
2. **轮换密钥**：开发期用过的 `DKNOWC_API_KEY` 视为已泄露，在 dknowc 控制台**吊销并换新**；生产 Key 只经部署环境变量注入。
3. **全新会话密钥**：目标环境设独立的 `BB_JWT_SECRET` 环境变量，不要沿用开发机的 `data/jwt.secret`（该文件泄露即可伪造任意管理员会话）。
4. **目标环境重建数据**：`cases.db` 由 `ingest_cases.py` 从**已授权**数据源现场重建，不随包分发；跑 `python -m app.seed` 生成账号并强制改密。
5. **不直接对公网 `0.0.0.0`**：置于反向代理（Nginx/Caddy）之后，启用 HTTPS，并由代理拒绝含 `..`/`%2e` 的路径（应用层已修复路径穿越，代理再加一道）。
6. 生产用多进程时注意：登录限流与 SQLite 单连接为单进程内存态；建议单进程 + 前置代理，或将限流/会话外置。

## 实现说明（与设计文档的差异）

以轻量为先做了三处等价替换：SQLAlchemy → 标准库 sqlite3（两张库：app.db 业务留痕 / cases.db 类案只读）；sse-starlette → FastAPI 原生 StreamingResponse；UI 框架 → 自研设计系统（无第三方组件库，全站 gzip ~65KB）。其余与《整体设计-v0.2.md》一致。
